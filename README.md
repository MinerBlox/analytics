# Affiliate Analytics

A lightweight dashboard preview for tracking affiliate earnings, referrals, traffic, and campaign performance.

## Preview

Open `index.html` in a browser. This is a static front-end prototype with clearly illustrative demo figures. It does not connect to an account, database, or external service. Changes made in the demo are stored only in the current browser.
